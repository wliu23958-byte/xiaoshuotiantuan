# 设定权威

哪些文件是《合缝》设定的唯一真源，写任何东西之前该先读哪几份，以及发现冲突时按什么顺序裁。

调度与工具用法不在这里，见 [团队手册](../团队手册.md) 与 `.cursor/rules/pchat-session.mdc`。

## 开工前读这几份

| 文件 | 它是什么的权威 |
| --- | --- |
| `01-设定/名词表.md` | **命名**。专有名词的唯一写法、禁用词、关键数字、沾锈台账 |
| `01-设定/时间线台账.md` | **年份与年龄**。所有绝对年份、入器次数、时长与沾锈刻度 |
| `01-设定/核心设定.md` | **硬规则**。金手指的四条约束、修复工序、世界观边界 |
| `01-设定/人物设定.md` | **人**。说话方式、能力边界、动机、成长弧线 |
| `02-大纲/总纲.md` | **结构**。五卷划分、单元排布总表、体量口径 |
| `02-大纲/谜团台账.md` | **未知的库存**。每个谜团的提出 / 加深 / 解答章号与实时存量 |
| `02-大纲/非盟器单元案例库.md` | 支线单元的器物与案情 |

写正文另加 `00-调研/写作规范.md`（字数、爽点间隔、章末钩子）和本章所在卷的细纲。

**凭记忆写是本仓最贵的一类错。** 第一卷初稿全线崩过一次，起因就是有人凭记忆写年份：「二十年前」和「七年前」两套说法并存，按两条线同时算，沈砚在爷爷死的时候只有六岁，而他七岁才落水——等于爷爷得在死后一年把他补回来。整条主线的根基就塌了。

## 目录归属

一个目录一个主责角色。这既是权威边界，也是[并行会话](./parallel-sessions.md)的地盘划分。

| 目录 | 主责 | 内容 |
| --- | --- | --- |
| `00-调研/` | 总编 | 市场调研、竞品拆解、写作规范 |
| `01-设定/` | 设定师 | 世界观、人物、名词表、时间线台账 |
| `02-大纲/` | 大纲师 | 总纲、卷细纲、`章纲/` 下的逐章章纲、谜团台账 |
| `03-正文/` | 主笔 | 章节文件，`第NNN章-标题.md` |
| `04-审校/` | 审校 | 审校记录 |

`src/`、`vite.config.ts` 这些是在线书架应用，只消费 `03-正文/`，不产生设定。改它不需要走设定流程。

## 名词表同时是给机器看的

`check-facts.mjs` 直接解析 `名词表.md` 的表格，所以**列顺序和一行一条的格式不能动**。

由此有两条反直觉的做法：

- **要加一条检查，去名词表加一行，不要改脚本。** 脚本自己不含任何设定。
- **机检报了一处而那处确实是对的，回来把它登记进去，不要放宽脚本。**

改名词表里的任何一条之前先想清楚：它一旦进表，全库出现的每一处都会被机检盯住。

## 用名词表登记的写法

输出里凡是提到设定概念——审校记录的标题、任务书的验收条件、黑板上的契约、章纲的字段——都用名词表里那个写法，不要漂移到它明确避开的同义词。

禁用词表就是这么来的：七件青铜器里没有鼎，第 10 章原写「有鼎」；那件盉是五年前入库的，「送来三年」是把沈砚刷锈的年头安到了器上。这两处都不是笔误，是有人用了自己顺手的说法。

**要用的概念表里没有**，那是个信号：要么你在发明设定里不存在的语言（重新想），要么确实是个真缺口（登记它，别绕过去）。

## 三个数字类台账，各管各的

它们容易被混着用，实际分工是硬的：

- **沾锈**记在名词表与时间线台账，只能单调递增。唯一例外是卷五的「放人退锈」，且必须明写机制
- **谜团存量**记在谜团台账，任一时刻不低于 8 个。解一个补一个，单元收束时对一次账
- **正文里出现的任何量化值**——百分比、秒数、毫米、次数——都必须在台账里查得到

最后一条是有代价的，那个税是故意收的。第 13 章的「沾锈从 0.9 涨到 1.8」和「上回你停了十七秒」当时只活在那一句对话里，台账查不到。**一个只存在于正文对话里的数字，等于没有定义**，下一个写手会自己编一个新的出来。

## 冲突按什么顺序裁

**正文已写的优先不动，设定和大纲让步。** 正文是最贵的资产，改一句要牵动上下文和读者记忆；大纲和设定是活文档，改起来没有代价。只有正文**自相矛盾**时才动正文，而且挑改动面最小的那一处下手。

**报冲突之前必须打开源文件确认原文。** 凭印象报错比漏报更糟，它会让人去「修」一个本来没错的地方。曾经有一次审校报告「正文写六道工序、核心设定写八道」，打开设定一看，补人本来就是六道、八道说的是器修复，两者从一开始就是分开的——真正错的是第三个文件。每报一条都要带上 `文件:行号` 和原文，引不出来的不要报。

**有些矛盾是故意留的伏笔。** 「古铜张第五代只有沈砚一个」与后文「炉头也是这一脉」看起来打架，这是有意的，已经复核过。遇到疑似矛盾**先去 `04-审校/` 翻历史记录**，那里记着哪些已判定为故意保留。

## 改设定要走的流程

设定一旦被大纲或正文引用就已经锁定，改它不是编辑一个文件那么简单。

1. 在黑板提 `kind=decision`，说清改什么、为什么、已经有哪些地方引用了它
2. 总编确认
3. 改设定文件，同步改名词表 / 时间线台账里的对应行
4. `send_to_session` 通知所有已引用的成员

跳过第 1 步直接改，结果是同一个设定有两个版本在跑，而且没人知道哪个新。这正是「第八件 / 第七件」在第四卷细纲里自相矛盾的成因——两轮人工审校都没抓到它。

发现设定级问题时**不要自己拍板**：写进黑板 `kind=risk` 并通知责任人。能直接改的错字、数字、时间才自己改并记录。
