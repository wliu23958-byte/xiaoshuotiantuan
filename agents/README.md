# agents

给 agent 会话看的操作约定。分工与角色见 [团队手册](../团队手册.md)，通道与工具用法见 `.cursor/rules/pchat-session.mdc`，具体动作见 `.cursor/skills/*/SKILL.md`。

本目录只写这三处**都没有**的东西：仓库层面的权威边界、问题往哪登记、流程的落差、多会话共写一棵树的做法。

| 文件 | 什么时候读 |
| --- | --- |
| [domain.md](./domain.md) | 写任何东西之前。哪些文件是设定真源、冲突按什么顺序裁、改设定要走什么流程 |
| [workflow.md](./workflow.md) | 认领一章之后。一章怎么走、跑哪几个机检、红线在哪一步生效、本机踩过的坑 |
| [issue-tracker.md](./issue-tracker.md) | 发现问题时。审校记录、黑板、PChat 任务分别装什么 |
| [triage-labels.md](./triage-labels.md) | 写审校记录时。严重度、归属、状态、退出码的口径 |
| [parallel-sessions.md](./parallel-sessions.md) | 多个窗口同时在写时。地盘、台账争用、精确暂存、报什么不报什么 |

新人按 `domain.md` → `workflow.md` 的顺序读，其余两三份用到再翻。
