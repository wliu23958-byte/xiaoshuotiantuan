## 禁用词

出现即报错。左列是禁用写法，右列是为什么。

| 禁用 | 原因 |
| --- | --- |
| 鼎 | 七器里没有鼎。第 10 章原写「有鼎」已改「有爵」 |
| 第八件器 | 青铜器总数永远是七。沈砚是「第七件」，不是第八件 |
| 送来三年 | 那件盉是五年前（2021-10-11）入库的。三年是沈砚刷锈的年头 |
| 案二案三补足 | 卷一沾锈已拆细为案一 1.8% + 案二 1.2% + 案三 0 |
| 落在同一个位置 | 沾锈落点有规则，入器者与守器者落点不同 |
| 三年养成 | **沾锈只有五十来天，不是三年。** 与「送来三年」同根：三年只能指沈砚刷锈的年头。看手、验锈这类围着锈长出来的习惯，起点是第 1 章那夜（第 0 天），到第 49 章才第 53 天 |
| 三年前它第一次出现 | 同上。虎口那块锈第一次出现是第 1 章，不是三年前 |
| 三年他身上的锈 | 同上。锈不是三年的，是五十来天的 |
| 付了三年的账 | 同上。他付的那笔账是这五十来天付的 |
| 姜宁这三年 | **新一族，2026-08-21 加，管的不是沈砚是姜宁。** 她二〇二六年进站、博士后第一年（`第056章:35`），二〇二七年第二年；她与沈砚这条线的起点是第 0 天。**全书总跨度只有十六个半月，装不下三年。** 卷四写「这一年多」，卷五写「这一年多」，指职业信用时不给数字、写「她做这一行以来」。定锤全文见 `01-设定/时间线台账.md`「姜宁干了几年」 |
| 她这三年 | 同上一族。**登记时 `03-正文/` 零命中，所以它不误伤任何既有正文**；四十多处合法的「这三年」全是「他这三年」（沈砚），一处都不会被这一条碰到 |
| 姜宁三年 | 同上一族，兜住「姜宁三年来」「姜宁三年里」这一类。登记时 `03-正文/` 零命中 |
| 三年来她 | 同上一族，兜住主语后置的写法（`第四卷章纲:109`「三年来她面对任何一件说不清的东西」就是这个形状）。登记时 `03-正文/` 零命中——现有两处「三年来」是 `第019章:112` 与 `第032章:7`，都是「三年来他」，不受影响 |

> **上面那四条看着像冗余，不许合并成一条「三年」。** `check-facts.mjs` 的 `checkBanned` 是纯字面 `includes`：写「沾锈三年」一处都抓不到（正文里根本没有这四个连在一起的字），写「三年」则会把十多处**合法**的刷锈年头全部变成误报——022:163、024:45/87/95、030:79/121、039:109、044:33/65 这些全是对的，一个都不能动。所以只能一种错误写法一条字面。
>
> **代价要知道**：这四条只拦得住这四种句式，换个说法照样漏。第 50~55 章就漏过九处（「这个规矩立了三年」「跑了三年的表」这一类），是主笔自己人读发现并清掉的，机检一处都没报。**碰到新句式就回来加一条，别指望现有这四条兜底。**
>
> 正面替身见「其他登记数值」的**五十三天**——那是第 50 章当天的实际天数。

## 重复数字（2026-08-15 立，管的是「同一个数反复出现」这件事）

**为什么要这张表**：卷一章纲审校扫出来，「十七」在卷一正文里至少七处、「十九」至少七处，而名词表原来只数了登记过的那两三处，于是备注里写着「这是第三处」的地方，实际是第六第七处。**零散备注管不住这件事，得有一张表。**

**裁定：同数复用在本书是有意的母题，但只对两类数成立，其余三类不算复用、不进这张表。**

| 类别 | 算不算复用 | 理由 |
| --- | --- | --- |
| **人身上的数** | **算，而且是母题** | 沈砚十九岁失去爷爷（第 3 章）、沈鹤年十九岁被錾子划破虎口（第 14 章）——两个人同一个岁数，这不是巧合，是这一脉「每一代都在同一个地方栽同一跤」的写法 |
| **测量值** | **算，要管** | 十七秒、十七毫米、十七格、十七件、十九条、十九年、十九天、十九件…… 这一类一多，读者就分不清哪个是线索 |
| 环境常数 | 不算 | 地下二层恒温十九度、地下三层十七度是**同一个事实反复出现**，不是同一个数被反复使用 |
| 日期与时刻 | 不算 | 三月十七日、三月十九日、四点十七分。日期本来就该有数，不与测量值同池 |
| 计数词 | 不算 | 「两条」「三张」「一遍」这类。全书遍地都是，管它没有意义 |

**口径：饱和算的是「作为线索被反复引用」的次数，不是「出现」的次数（2026-08-15 总编裁定）。** 一个数出现在表单、档案栏位、报告这一类地方，而叙述并不回头去引用它，**不计入饱和**。上面那张表分的是哪些数要管，这一条定的是怎么数——两条一起用：先看它属不属于该管的类别，再看叙述有没有拿它当线索反复提。

**这条比任何一次具体选数都重要**，它是十九天那件事（见本节末）真正的争点：同一个数在表单上出现一次和在三章里被人反复念，是两回事。裁定采方案 A 是另一层考虑，不是这条口径推出来的结论。

> **查数字不等于查概念（2026-08-18 立，通道 3 提，起因是一次真实的漏网）。**
>

>

>

**反射变换成像（RTI）** —— 支线 8 用的方法，第 194、197、199、200 章。同一台相机固定不动，只换光的方向连拍一组（本书这一次是四十八张，四圈、一圈十二个位置），由高光位置反算出石面每一点朝哪儿，此后光就不再是灯给的，可以在屏幕上任意重放。

**它与馆里别的检测有一条分界，写这几章时要守住**：别的检测是把**已经在那儿**的东西量出来（风化层多深、元素是什么、断口新不新）；这一次是把**本来看不见**的东西显出来。所以它给的不是一个数，是一幅像——而像要人去认，认就有判断，判断就要有人签字。支线 8 的两难正压在这上头。

**称呼分两层，不要混**：现场与对话里叫「多角度打光」（第 194 章章名就是它，该章正文里一次全称都没有出现，这个处理是对的）；**全称只在正式书面文字里用**。**「RTI」这三个字母不进正文**，本页留着它只是为了让人查得到。

**报告里那一条记录，正文已定稿，逐字照抄，不要改写**（`第200章:21`，2026-08-18 补引；原先本行引的是章纲 `:502` 那句「志文第某行」，**那是落笔前的占位说法，已失效**）：

> 盖顶面篆额第一行第三格残存刻痕经反射变换成像辨识，内容存疑，原样保留，不做补刻。

**「第一行第三格」把一件悬着的事钉死了**：篆额是**三行三列共九格**，被磨掉的是**第一行第三格**（篆书竖排从右起）。这与上文「五十八厘米 / 十厘米」那一行说的「顶面九格」对得上，也与第 191 章一致。**卷四若有人再写这方石头，位置按这个用，别自己数。**

## 清点间与临时工作室（桐城，2026-08-20 立）

**这两个词不是两个名字在打架，是各司其职**，而且正文自己当场立了法（`第206章:3-4`）：章首地点戳写「二月二十五日上午八点四十，清点间」，紧接着下一行写「这间屋子从今天起算临时工作室」。

| 词 | 它是什么 | 怎么用 |
| --- | --- | --- |
| 清点间 | **屋子的名字**，桐城省博库区那间屋子本来就叫这个 | **章首那一行的地点戳一律写它。** 第 206、208~214、217、220、222、224、225 各章章首都是「日期＋清点间」 |
| 临时工作室 | **它从二月二十五日起被指定成的用途**，不是另一间屋子 | 正文行文里说「干活的场子」时用它，合法。`第208章:9`「工作室里就是四个人」就是对的，**不要当错误去改** |

**落笔口径三条**：一、说地方用清点间，说场子用工作室，按语感选；二、**章首地点戳不许写成工作室**；三、`02-大纲/章纲/第三卷章纲.md` 里那十几处「场景　工作室」**不是错的**（:698 第 220 章、:714 第 222 章、:730 第 224 章等），**不要去改章纲**——按正文优先让步的前提是两者矛盾，而这里不矛盾。

> **登这一条的方向是有讲究的，别登反。** 本条最初的报法是「正文一律写清点间，不写作工作室」，那是从「章首全是清点间」这个现象直接跳出来的结论，少了一步。**照那个方向登，下一个人会拿它当尺子去改 `第208章:9`，而那一句是对的。** 现象是真的，规则不是那一条——反例里往往不是错，是还没看见的那条规则（2026-08-20 总编收窄口径后，由主笔 B 落地）。
