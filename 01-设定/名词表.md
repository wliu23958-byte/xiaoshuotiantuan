# 名词表

**这份文件同时是给人看的和给机器看的。** `check-facts.mjs` 直接解析下面的表格，所以**格式不能随便改**：每张表的列顺序固定，条目一行一条，不要合并单元格。

改任何一条之前先想清楚：它一旦进了这张表，全库出现的每一处都会被机检盯住。

跑机检：

```powershell
[Console]::OutputEncoding=[Text.Encoding]::UTF8; node .cursor/skills/novel-fact-check/scripts/check-facts.mjs
```

机检报了一处而那处确实是对的，**回来把它登记进去，不要放宽脚本**。

## 禁用词

出现即报错。左列是禁用写法，右列是为什么。

| 禁用 | 原因 |
| --- | --- |
| 鼎 | 七器里没有鼎。第 10 章原写「有鼎」已改「有爵」 |
| 第八件器 | 青铜器总数永远是七。沈砚是「第七件」，不是第八件 |
| 送来三年 | 那件盉是五年前（2021-10-11）入库的。三年是沈砚刷锈的年头 |
| 案二案三补足 | 卷一沾锈已拆细为案一 1.8% + 案二 1.2% + 案三 0 |
| 落在同一个位置 | 沾锈落点有规则，入器者与守器者落点不同 |

## 关键数字

同一个概念只能有一个数。写到这些数字时先来对一遍。

| 数值 | 含义 | 不要混淆 |
| --- | --- | --- |
| 2.3% | 沈砚身上补配的缺口 | 与盉的 1.4% 不是一回事 |
| 97.7% | 沈鹤年补沈砚的完成度 | 100 − 2.3 |
| 1.4% | 那件青铜盉的永久性缺损 | 与沈砚的 2.3% 不是一回事 |
| 98.6% | 沈砚把盉修到的完成度 | 100 − 1.4 |
| 3.0% | 卷一末沾锈 | 案一 1.8 + 案二 1.2 + 案三 0 |
| 29.4% | 卷五沾锈峰值 | 血条上限是 30% |
| 五年 | 那件盉入库至今 | 沈砚刷锈是三年，别串 |
| 七年 | 沈鹤年去世至今（2019→2026） | 「二十年前」只能指他 2006 年南下 |
