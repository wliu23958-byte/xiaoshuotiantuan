# 事实体检

`check-format.mjs` 管排版，这一份管**说得对不对**。

## 为什么需要它

第一卷十五章做过两轮人工审校，每一轮都是全文交叉比对时间锚点、数字、专业细节。抓出来的东西包括：两套时间线并存、七件盟器里混进一件鼎、沾锈落点没规则、单元长度三份文档三个数。

问题是这套方法**不可扩展**。九万字做得动，四十五万字做不动，一百五十万字绝无可能——每新增一章，要比对的既有事实就多一层，是 O(n²)。而且它已经漏过：两轮审校都没发现「第八件 / 第七件」在第四卷细纲里自相矛盾。

但上面这些硬伤**几乎全是机器可验的**。所以有了这个脚本。

## 真源在名词表，不在脚本里

脚本自己不含任何设定，它只解析：

- `01-设定/名词表.md` —— 七姓七器、禁用词、人物、关键数字、其他登记数值、沾锈台账
- `01-设定/时间线台账.md` —— 所有年份

**要加一条检查，去名词表加一行，不要改脚本。** 反过来，机检报了一处而那处确实是对的，也是去名词表登记，不是放宽规则。

## 查什么

| 项 | 规则 |
| --- | --- |
| 禁用词 | 名词表登记的旧说法（鼎、第八件器、送来三年…），正文出现即错 |
| 半角标点 | 中文之间夹了半角 `,;!?:`。全书统一全角 |
| 百分比 | 正文里每个 `X%` 都必须登记过。这是为了抓 2.3 写成 2.4、98.6 写成 98.7 这类漂移 |
| 年份 | 每个四位年份都必须在时间线台账里。**中文与阿拉伯两种写法都认** |
| 沈姓人名 | 正文里的「沈X」必须是登记过的人。虚词靠停用字表滤掉 |
| 沾锈单调性 | 血条只能升不能降，回跳即报 |

## 跑

```powershell
[Console]::OutputEncoding=[Text.Encoding]::UTF8; node .cursor/skills/novel-fact-check/scripts/check-facts.mjs
```

Windows 下不设编码会输出乱码。`--dir=路径` 可以指到别的目录，用来测脚本本身。

干净退出码 0，有问题退出码 1。

## 另一个脚本：章纲体检

`check-facts.mjs` 查正文，`check-outline.mjs` 查 `02-大纲/章纲/` 下的逐章章纲。

```powershell
[Console]::OutputEncoding=[Text.Encoding]::UTF8; node .cursor/skills/novel-fact-check/scripts/check-outline.mjs
```

五百章的章纲靠肉眼查章号和字段不现实，它管四件事：

| 项 | 规则 |
| --- | --- |
| 章号 | 在本卷范围内连续、不重复、不越界。缺哪几章直接列出来 |
| 字段 | 每章五个字段齐全：场景 / 出场 / 信息增量 / 不许泄露 / 章末钩子 |
| 沾锈 | 数值**只能出现在单元收束章**。中间章写了沾锈就是拆错了 |
| 禁用词 | 与 `check-facts.mjs` 共用名词表那一份真源 |

各卷的章号范围写死在脚本顶部的 `VOLUMES` 里，改卷次结构时记得同步。

**它管不了的**：情节因果、伏笔有没有回收、有没有提前泄露谜团台账里排在后面的答案。那些仍然要人对着 `谜团台账.md` 看。

## 第三个脚本：全书重复数字

`repeated-numbers.mjs` 回答一个前两个脚本都答不了的问题：**同一个数被用了几次，各在哪里，分别是什么量纲。**

这本书里同数复用是真实存在的——十七秒、十七毫米、十七件、十七格；十九度、十九岁、十九天、十九条、十九年。它是有意的母题还是撞车，得先看清全貌才谈得上。而这笔账此前一直**靠备注手数**，两处都数少了：名词表写着「十七已有两处」（只数了它自己登记过的），卷五审校写着「第 404 章那个十九年是全书第三个十九」（没扫正文）。实扫卷一二十章，十七是第六到七处，十九至少第七个。人记不住这种账。

```powershell
[Console]::OutputEncoding=[Text.Encoding]::UTF8; node .cursor/skills/novel-fact-check/scripts/repeated-numbers.mjs
```

| 开关 | 作用 |
| --- | --- |
| `--from=N` | 从多大的数开始数，默认 10 |
| `--min=N` | 只列配了 N 种以上量纲的，默认 2 |
| `--value=十七` | 只看一个数，列出每一处原句与章号 |
| `--outline` / `--all` | 改扫或加扫 `02-大纲/章纲/` |
| `--max=N` | 有数超过 N 种量纲就退 1 |

**为什么默认从十起数**：汉语里「一件」「三道」「两只」的一二三是不定冠词不是数量。第一版没滤，「一」报出 24 种量纲 495 处，把真正要看的全埋了。读者会觉得「这个数怎么又出现了」的，是有辨识度的数。

**它默认永远退 0，因为它不下判断。** 这一点和另外两个脚本相反——那两个查的是对错，这一个摊的是账。要把结论钉成会失败的检查，用 `--max=N`。

**总编已经拍过一次板了**（2026-08-15，名词表「重复数字」表）：同数复用在本书**是**有意的母题，但只对**人身上的数**与**测量值**两类成立；环境常数、日期时刻、计数词不算。**那三类脚本里已经按裁定滤掉**——日期时刻单列不计，计数词靠 `--from` 阈值挡，环境常数（恒温十九度、地下三层十七度）靠前缀识别挡，滤了多少处在输出头部报。裁定同时判了**十七与十九已用饱和**，后面新写的测量值一律避开。

（跨卷的沾锈链、入器次数与谜团存量另有 `book-ledger.mjs`，用法见它自己的文件头。）

## 第四个脚本：人名漏网

`unregistered-people.mjs` 补的是 `check-facts.mjs` 的一个死角：**它的 `checkShenNames` 只验沈姓**，别的姓一个都不查。

而名词表「人物」一节开头写着「正文里出现的人名必须在这张表里」。这两句话之间的缝里已经掉过五个人，**五次都是靠人肉查重时顺手撞见的**：何同志（41~60 章）、小徐（61~70 章）、乔副馆长（37~39 章，有姓有台词还签了字）、刘副主任（21、23、36 章）、白老师（46~47 章）。第六次不该再靠运气。

```powershell
[Console]::OutputEncoding=[Text.Encoding]::UTF8; node .cursor/skills/novel-fact-check/scripts/unregistered-people.mjs
```

它扫两种形状：**姓＋职务**（乔副馆长、白老师、刘副主任）与**小／老＋姓**（小徐、老毛）。姓表取常用百家姓，**宁可少收不可多收**——漏一个姓只是这轮没报，多收一个（「和」「有」这种）会把每章都刷成误报。

**它退出码恒为 0，不进 `npm run check`。** 判「像不像人名」做不到零误报，拿它当门禁只会教人学会忽略它。

**用它之前先懂一件事：这个脚本的价值全在于报告是不是空的。** 「小沈」「周主任」「沈老师」这些别称每次都会命中，十来条常驻噪音会让人跳过整份报告，于是真正的新漏网夹在里面也没人看见。所以脚本会读名词表人物表下面那张**「上表这些人的别称」**，把第一列按「/」拆开并入已知名单。**查证过的别称与误报（比如「那师父」其实是「那，师父……」的断句）就加进那张表**，报告才回得到空。2026-08-18 首次运行报了 14 条，登掉 2 个真人、归档 12 条别称与误报之后，它现在是空的——**下一条冒出来的就是新的。**

**一处真撞车是它扫出来的**：「小周」在本书里指两个人——沈鹤年回忆里的周维（第 8、19 章那两句最重的台词），和卷二陈延手下那个开车的刑警（157~164 章）。人物表里已写明，等作者拍板。

## 两个已知的取舍

**只扫 `03-正文`。** 设定和大纲会正当地讨论禁用词（「原写作第八件，已统一」「原写作送来三年，已改」），在那里查全是误报。真正会砸在读者脸上的只有正文。

**百分比要求全部登记，这个税是故意收的。** 新写一个测量值就得去名词表加一行——顺手也就把它眼看一遍。如果哪天章节多到这件事变成负担，再改成「只报与登记值相近的可疑漂移」，但那样会漏掉真正的新错。

## 工作流

写完或改完任何章节：

1. `check-format.mjs` —— 排版
2. `check-facts.mjs` —— 事实
3. 两个都退出码 0 才提交

机检干净不等于没有连续性问题。**人物动机、情节因果、伏笔有没有回收，机器一概不管**，那些仍然要人看。这个脚本的作用是把人从数字核对里解放出来，去干只有人能干的部分。
