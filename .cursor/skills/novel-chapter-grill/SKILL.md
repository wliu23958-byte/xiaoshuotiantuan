# 审稿：往死里挑

## 立场

**不许说"整体不错"。** 这个 skill 存在的意义是找出问题，不是给鼓励。稿子的优点不用你夸，作者自己知道。

第一卷初稿曾经因为"二十年前"和"七年前"两套说法并存而全线崩过一次——按那两条线同时算，沈砚在爷爷死的时候只有六岁，而他七岁才落水，等于爷爷得在死后一年把他补回来。整条主线的根基就塌了。**这种问题不会自己浮出来，只能一条一条对表。**

## 铁律：报错之前必须打开源文件确认原文

**凭印象报错会制造假问题，比漏报更糟**，因为它会让人去"修"一个本来没错的地方。

实战教训：曾经有一次审校报告"正文写六道工序、核心设定写八道，两边冲突"。打开设定一看，`核心设定` 本来就写着补人是六道、八道说的是器修复，两者从一开始就是分开的，根本不冲突。真正错的是第三个文件（时间线台账）。**如果当时先打开文件确认，就不会误报，也不会差点改错正文。**

所以：每报一条，引用里必须带上 `文件:行号` 和原文。引不出来的，就不要报。

## 开工前必须读的五份

不读就审等于凭记忆瞎猜，凭记忆瞎猜就是上一次崩盘的原因。

| 文件 | 用来查什么 |
| --- | --- |
| `01-设定/时间线台账.md` | 所有绝对年份、人物年龄、入器次数、时长与沾锈刻度 |
| `01-设定/人物设定.md` | 说话方式、能力边界、动机 |
| `01-设定/核心设定.md` | 金手指规则、修复工序、世界观 |
| `00-调研/写作规范.md` | 单章字数、爽点间隔、章末钩子 |
| `02-大纲/` 对应卷的细纲 | 本章该完成什么、不许提前泄露什么 |

再加上**被审章节前后各两章的正文**。跨章冲突只能靠读正文发现。

## 八道检查

按顺序过，每一道单独出结论，不要混在一起讲。

### 一、大纲与正文对账（优先级最高）

**这是收益最大的一道，因为大纲是后写的、改得勤，最容易和已经落地的正文脱节。**

实测下来，第 1~15 章的正文本身几乎挑不出硬伤，但大纲里挤着好几处和正文直接打架的地方。所以不要只把细纲当"本章要写什么"的说明书读，要**反过来验证细纲对正文的每一处描述是否属实**。

三种高频失效模式，每次都要专门查：

1. **大纲声称的事实，正文里是另一个样子。**
   例：正文第 3 章明写工具箱盖上第三个名字是郑立恒、沈砚当场认出；大纲却写"第三个他还是不认得"。
2. **同一个数字被安到了两个对象上。**
   例：1.4% 在正文第 10 章是**青铜盉**的永久性缺损，大纲却把它挪到沈砚身上当补配缺口。现已拆成盉 1.4%、沈砚 2.3%。
   查法：把本章出现的每个百分比、尺寸、编号列出来，逐个问"这个数属于谁"，再全库搜一遍看有没有第二个主人。
3. **大纲说"第一次出现"，但正文早就出现过。**
   例：大纲把某句台词标成"全书主旨第一次被完整说出"，可前面两章已经分别讲过机制和嘱咐。
   查法：凡是细纲里写着"第一次""首次""终于"的地方，全库搜那个概念，确认前面真的没出现过。

### 二、时间线

把本章出现的每一个时间表述抠出来列成表：绝对年份、相对年数（"七年前"）、人物年龄、时刻、时长、间隔。逐条对 `时间线台账.md`。

**五个已知易错点，每次都要专门查一遍**：

1. "二十年前"只能指沈鹤年南下（2006）。他的死、偷胶、借镜、留字条全部是**七年前（2019）**
2. 沈砚十九岁时爷爷去世，不是七岁。七岁那年是他自己死的那次
3. 周维 2011 年就有四楼钥匙，2019 年三月台账被裁那十八天他**有**作案条件——不要写成他没钥匙
4. 郑立恒死于**当夜十一点四十**，不是下午。下午四点十七分是他打给省博的电话
5. 入器次数是血条刻度，每写一次要回台账记一笔

### 三、数字，以及数字有没有进台账

时长、距离、次数、百分比、尺寸、编号。**任何一个数字都要能和前文对上。**

重点查累加类：入器第几次、沾锈百分比、章节内经过的时长。

**外加一条**：正文里出现的任何量化值，**台账里必须查得到**。查不到就是缺格，要当问题报。

实战教训：第 13 章的对话里有"沾锈从 0.9 涨到 1.8"和"上回你停了十七秒"，这两个数当时只活在那一句对话里，台账的对应栏是空的。下一个写手查不到，就会自己编一个。

沾锈必须**单调递增**，不许回跳。唯一例外是卷五的"放人退锈"，且必须明写机制。

### 四、人物

- **沈砚话极少，一次不超过两句**，急了也不提高声音。唯一豁免是讲器——讲器可以长篇大论。注意分辨：讲**自己的能力**不算讲器，那是越界
- **姜宁不能变成万能仪器。** 她连续用设备给沈砚背书超过两次，就必须安排一次测不出来的失败，否则悬疑张力会被实验室吃干净
- **周维不是反派。** 他是每天给你打饭、也确实在骗你的人。任何把他写扁的地方都要标出来
- 老猫给的东西永远是"顺手"的，他不会主动解释
- **配角别撞设定**：两个权威老人同龄、两个人共用一个口头禅这类，虽不致命但会糊，一并报出来

### 五、金手指边界

入器有四条硬约束，越界就是崩设定：

1. **残缺对应残缺**——器修到几成，看到几成。想看全就得修完
2. **只进不出**——入器时他在现实里站着、手还在动，但那不是他在控制
3. **代价是记忆**——入一次顶掉一段，越往后掉得越深
4. **沾锈**——只有持有者横死才留印

触发条件同样是硬的：必须**他亲手**修复、断口两端在**他手里真正对合**。机器拼不算，别人拼不算，抢先上胶不算。

还有一条第 13 章定死的：**器认的不是最后一个用它的人，是最后一个把它交出去的人。** 全书结局的机关就架在这条上，任何与它相悖的写法都要报。

### 六、专业细节

工序、病害名称、材料、力学常识**必须真实**。器物、墓葬、人物可以虚构，专业常识不能虚构。

存疑的地方直接标出来要求核实，不要放过。这是本书的壁垒，错一处就塌一片。

### 七、节奏

- 单章字数够不够（长版定的是 3000 字/章）
- 章末有没有独立成段的钩子
- 距离上一个爽点超过两章没有
- 情绪浓度：连续两章高浓度之后，下一章必须冷下来走查证、报表、程序，一句抒情都不要

### 八、红线

- 不写具体盗掘手法与文物交易渠道细节
- 灵异一律限定在"器物残留信息"框架内，不写鬼神施法
- 不碰政治敏感与过度血腥

## 输出格式

```markdown
# 第 N 章审校

## 致命伤
（会让主线根基塌掉的。没有就写"无"，不要凑）

**问题**：一句话说清冲突长什么样
**证据**：`文件:行号` 的原文，与另一处 `文件:行号` 的原文对照
**该改哪边**：正文已写的优先不动，设定和大纲让步；只有正文自相矛盾时才改正文
**建议改法**：具体到改哪个词

## 硬伤
| # | 位置 | 问题 | 该改哪边 | 建议 |

## 复核通过、不用改的
（列出你专门查过但确认没问题的，让下一个审校知道哪些已经被覆盖了。
这一节很重要，不要省——它决定了下次审校能不能少走一遍。）

## 留给主笔的提醒
（针对下一章的前瞻建议，最多三条）
```

## 三条纪律

**一、正文已写的优先不动，设定和大纲让步。** 正文是最贵的资产，改一句要牵动上下文和读者记忆；大纲和设定是活文档，改起来没有代价。只有正文**自相矛盾**时才动正文，而且要挑改动面最小的那一处下手。

**二、拿不准的不要当错处改掉。** 有些矛盾是故意留的伏笔。比如"古铜张第五代只有沈砚一个"与后文"炉头也是这一脉"看起来打架，这是**故意的**，上一次审校已经确认过。**遇到疑似矛盾先去 `04-审校/` 翻历史记录**，那里记着哪些是已经复核通过、判定为故意保留的。翻不到再问。

**三、发现设定级问题不要自己拍板。** 涉及设定或情节走向的，写进黑板 `kind=risk` 并通知责任人。能直接改的错字、数字、时间才自己改并记录。改完记得回写 `04-审校/`，让这一轮的结论沉淀下来。
