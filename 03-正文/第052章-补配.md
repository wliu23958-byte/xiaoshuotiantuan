# 第五十二章　补配

九月二十四日上午八点五十，临时工作站。
补配用的铜片是沈砚自己带来的。
一小块，比火柴盒略大，压在工具包最底下一层，用软纸包着。这是他从省博带出来的料，纯铜片，退过火，锤起来听得出闷。
它跟台上那件东西不是一路材料，差得很远。
差得远是有意的。
红灯八点五十二分亮起来。
何同志在表上写今天的第一条：上午八时五十二分，开始补配作业。
年轻那位监督员今天站得比前几天靠前。前几天他多半在门边，靠着墙看手机，隔一阵抬一次头。今天他站到了台角，两手插在制服口袋里，看沈砚把那块铜片摊开。
看了十来分钟，他开口了。
“沈老师。”
“嗯。”
“我能问个事吗。”
沈砚没有抬头。
“问。”
“这东西不是假的吗。”
何同志的笔停了一下。
年轻人自己也听出来这话有点硬，往回收了半句。
“我不是说别的意思。”他说，“我就是不明白。它是个赝品，是证物，回头还要移交。你干嘛还这么补它。”
沈砚把铜片翻了个面。
“你觉得该怎么补。”
“随便糊一下不就行了。”
沈砚没有说话。
他把那块铜片夹起来，放到砧上。
砧是木的，硬木剜出来的窝，中间那道弧是他自己修出来的。锤子是小锤，锤面磨得很光。他左手扶片，右手起锤，落下去的时候手腕不动，力从肘上走。
一下，两下。
铜在木窝里一点一点往下沉，边缘慢慢卷起弧度。
年轻人以为他不打算回答了。
锤了大概二十下，沈砚开口。
“补配那道工序有两条铁规矩。”
“第一条叫可识别。补上去的东西，必须让后来的人看得出来哪一块是补的。远看是一件，近看能分辨。”
“第二条叫可逆。后来的人要是判断你补错了，得拆得下来。”
他停锤，把铜片对着灯照了一下弧度，又放回去。
“这两条是三千年的行规。”
“可它是假的。”年轻人说。
“是假的。”
沈砚把锤子放下。
“补到看不出来的，只有两种人。”
“一种是作假的。”
“一种是不打算让人知道自己补过。”
他抬起头。
“这件东西是假的，做它的人已经把第一种干完了。我要是再照他的路子补一遍，让人看不出来我动过手，那这件器上就有两个人的手，而两个人都不肯认。”
“以后不管谁打开它，看见的都是一层糊在一层上面。”
“这里头哪一层是三千年前的，哪一层是几年前的，哪一层是我昨天上的，就再也分不出来了。”
年轻人张了张嘴。
“我要留的不是它。”沈砚说，“我要留的是一份能被人拆开看的东西。”
他重新拿起锤子。
“它是假的，不影响这一条。”
姜宁在台子那一头，一直没有插话。
她低头在自己那个牛皮纸本子上写了一行。
上午九点二十，锤揲成形。
写完她没有把本子合上。
“我也问一个。”
沈砚看过去。
“那三份检测报告我昨天晚上又过了一遍。”姜宁说，“热释光那一项，三个取样点，全部落在西周晚期的区间里。”
“我知道。”
“我一直当它是做局做得好。”她说，“可热释光测的不是手艺。它测的是这件东西上一回被烧到高温以后，过了多少年。”
“这个数做不出来。你要么有那些年头，要么没有。”
她把笔帽扣上。
“台上这一件没有那些年头。”
“可它交出来的数有。”
沈砚没有回答。
他手里那块铜还压在砧上。
“我不问你怎么解释。”姜宁说，“我只是要你知道，这一张报告我解释不了，我把它记下来了。”
她说完就低下头去，没有再看他。
沈砚重新起锤。
锤子落下去的声音比刚才闷了一点。
那道要补的缺不宽。
它是拆的时候留下来的——沿着圈足内侧那道弧下刀，刀口再细也要吃掉一点料，四十度走下来，起开的那一片和器身之间空出一条极细的缝。缝比头发丝粗不了多少，可它是一整条，四十度，绕着圈足内壁走。
不补，那一片装回去就是浮的。
补，就得往一条弯的、内凹的、只有指头能伸进去的缝里嵌铜。
沈砚把成形的铜片剪成了三段。
一整条四十度的弧压不进去。压的时候要顺着弧线一点一点走，一整条会在中段拱起来，拱起来就顶壁；顶壁的地方受力，圈足那圈本来就薄。
三段。每一段十三度上下，两端各留一点搭口。
第一段在九点五十试装。
试装不上胶。他把那一段送进去，用竹签抵着推到位，再取出来，看两侧的接触痕，哪儿蹭亮了就锉哪儿。这一段他取出来锉了六次。
第六次送进去的时候，它自己停住了。
十点半，第二段。
第二段比第一段难，因为它两头都要接——一头接第一段，一头留给第三段。他锉了九次。
中间有一次他停了很久，久到年轻监督员往前凑了半步，以为出了什么事。
沈砚没有出事。
他在想一件跟手上这段铜片没有关系的事。
昨天他跟姜宁讲过一遍规则，讲得很顺：器认的不是最后一个用它的人，是最后一个把它交出去的人。这条规则从头到尾不问真假，所以一件仿品也认——认的是把它摆进展柜的那个人。
每一步都接得上。
可是接得上不等于讲通了。
他讲的是这条规则怎么用。
他没有讲这条规则凭什么能用在这件东西上。
一件真器在土里躺三千年，里头封着一个人。那是有东西的。
台上这一件，铜是几年前化的，范是几年前翻的，锈是几年前做上去的。它从头到脚没有一样是老的。
这么一件东西，凭什么能存住那一晚？
凭什么能让他站在那儿六分四十秒？
他把这个问题从头到尾摆了一遍，摆完还是那个形状：他能说清楚自己看见了什么，说不清楚自己为什么看得见。
这不是一个可以放着不管的洞。
它就在他前天那段话的正中间，而他前天没有看见它。
竹签在他手里转了半圈。
他把第二段送了进去。
十一点二十，第二段坐稳。
随色他先在这两段上做。
调色是拿原器上那几种颜色对着调的——绿里带一点土黄，圈足那一圈更沉。他调一次，用棉签在废铜片上点一笔，拿到灯下看，再调。前后调了很多次，每一次的差别小到旁人看不出来。
他要的不是一样。
他要的是隔一米看不出来，隔三十公分看得出来。
做完他把两段的表面又压低了一线。
这一线是刻意的。补配面比原器表面略低半线，眼睛看不出，指腹推过去能摸出一道极浅的台阶。
年轻监督员被叫过来摸了一下。
他推了两遍，第二遍推慢了。
“有。”他说。
“这就是可识别。”沈砚说。
“我刚才隔着一米看，真看不出来。”
“那就对了。”
下午一点整，姜宁把那盏紫外灯拿了过来。
灯是她自己的，手电大小，波长固定，平时用来看封护层有没有漏刷。
顶灯关掉，两盏臂灯也关掉。
屋里只剩摄像机上那个红点，和她手里那一束。
光打在圈足内侧。
原器那一圈是暗的、闷的，光落上去像被吃进去了。
补的那两段整个亮起来。
不是发白，是一种冷的、浮在表面上的亮。它跟旁边那一圈截然分开，边界清楚到能数出每一段的两头在哪儿。
年轻监督员往后退了半步。
“这么明显。”
“在这盏灯下明显。”姜宁说，“在展厅那种灯下，什么都看不见。”
“眼睛一种，手一种，仪器一种。”沈砚说，“三样里只要有一样认得出来，后来的人就骗不了。”
灯关了，顶灯重新亮起来。
何同志一直在记。
她记完抬起头。
“沈老师，这一条我怎么写。”
“写补配材料与原器材质可区分，紫外荧光下界面清晰。”
“就这一句？”
“再加一句。”
他说得很慢，让她跟得上笔。
“本次补配采用可逆固定，未做原位粘接，可整体取下。”
何同志写完，笔尖在纸上停了一会儿。
“这件东西不是真的。”她说，“这么写，会不会显得我们……”
她没有把那个词说出来。
沈砚知道她要说什么。
清河这边到现在还没有对外说过一个字。展签还挂在柜子上，展期还挂在墙上，一份写得规规矩矩的修复记录，将来会变成一份很难看的东西——它会证明这个馆按一级品的规矩，认认真真地修了一件假货。
“照实写。”沈砚说。
“记录不是给现在看的。”
下午一点四十，第三段。
这一段最短，两端都要接死，而且它落下去以后，圈足内侧那道弧就闭合了。
沈砚把它送进去了三次。
第一次偏了半线，取出来。第二次两端接触，中段虚着，取出来。第三次他换了角度，从弧的外侧起手，让铜片顺着壁一点一点往里滑。
滑到位置的时候，他没有推。
他把两只手都放上去，一只手扶着起开的那一片，一只手压在第三段的背上。
然后往下按。
压下去的那一刻，那条走了四十度的缝合上了。
断口两端在他手里对上。
不用力，不用工具。
它只是忽然不动了。
这一次他没有先看摄像机。
