# 第二百一十一章　第三天夜里 · 递工具

二月二十八日夜里九点二十，清点间。
灯只留了台上一圈。头灯、臂灯、门边记录那位桌上一盏小的，其余都黑着。库区夜里那种静把这间屋包在中间，排风的声音显得比白天大。
今天不归柜。
下午泡进缝里的溶剂，这会儿正吃到最深那一段。胶胀到一半，软到一半——这个时候停手，把器送回匣里搁一夜，溶剂自己散干净，软了的重新硬回去，硬回去的比原先还顽。今天下午的活儿就白做了。
要么不泡，泡了就得跟到底。
延时登记上写了通宵前半段。许主任批的，条件松了两处：馆方今夜留一个人守到收工，归柜那一条也免了——器留台，门上两把锁，明早原样点。记录不停。记录那位把小桌搬到门边，台灯拧到最低，本子摊着，人靠着墙，写一阵，靠一阵。
姜宁夜里没有来。明天最后一道要用她的机器，她在楼上备参数、排记录格式——最后一道是三个人的活儿。
今天夜里是两个人的。
台前，沈砚坐着，周维站着。
夜里的活儿跟白天不是一个做法。白天签走缝口，走的是面上的量；夜里溶剂把深处泡开了，签尖能进到白天进不去的地方——可也只有这几个钟头能进。窗口就这么宽，过了就关。
所以夜里的节奏更密。签进，带屑，退出来，刮皿沿；捻抽出来，看颜色，换新捻；隔一段试一次手温，隔两段换一次姿势。
一开始还有话。
话也只剩一个字了。
“捻。”
捻递过来。
“签。”
签递过来。
到十点过，字也省了。
沈砚发现的时候，是一支镊子。
他清完一段，签退出来，嘴张开，那个字还没出口——镊子已经到了，横在他手边，柄冲着他。
他愣了半拍，接了。
下一回是灯。
缝走到拐弯，他手上的活儿一收，刚要直腰，臂灯的角度已经变了，光从另一侧压过来，正落在弯上。周维的手从灯臂上收回去，退回原位。
再下一回是捻。
再下一回是那支偏刃的签。
再往后是洗耳球。缝口积了屑，签退出来，他手指刚离开活儿，那只软皮的球已经递到手边，吹两下，屑走了，球放回去，谁都没看谁。
没有一回递错。
起初每一样到手，沈砚还低头看一眼——对不对，是不是要的那一支。
后来不看了。
工具从那只手到这只手，从掌心直接进活儿里，中间那一眼，省了。省下的不是工夫，是别的东西。手上有数的人都知道那是什么，可谁也不会把它说出口。
递工具这件事，看着是下手的活儿，其实不是。一支工具递得对，要看懂的东西不比用它少：活儿到了哪一步，下一步是什么，下一步的下一步是什么；这一段缝要的是挑还是刮，是进还是退。看不懂的人，递十回错九回，错的那一回还打断人的手。
周维没有错过。
他站在台侧，看的不是热闹，是路。签走到哪儿，他的眼睛在前头半步等着。
停也有两种。
看的停：手悬着不退，头再低下去半寸——那之后要的是灯，或者放大镜挪个角度。
换的停：手先退半寸，指尖一松——那之后要的是下一支。
两种停在外人眼里是一回事。周维分得出。他不光分得出，他连要换成哪一支都分得出，因为他知道缝的下一段是宽是窄，是直是绕。
这间屋里没有第二个人做得到。楼上那几位也做不到。做得到的，得是一个自己修了半辈子器的人。
一个正高，一个劳务派遣。一个站着，一个坐着。
一句话没有。
被人看懂，是一件让手安静下来的事。
沈砚干活从来不指望旁边的人。要什么自己够，够不着就停下来去拿——停一次，手上的线就断一次，断了重新接。他习惯了，习惯到不觉得那是消耗。
今天夜里那根线没有断过。
从十点到现在，他的手没有离开过这道缝。要的东西自己来，来的都对，对到他不用分出半个念头去想下一样在哪儿。整个人收成窄窄的一条，全在签尖上。
这种干法他小时候有过。平房里，冬天，窗上钉着塑料布。台前坐着的那个人，工具也排得笔直，递东西的是他。递错了不挨说——那只手就悬在半空，不接，也不催，等他自己看出来该换哪一支。
他没有让这个念头往下走。缝要紧。
十一点，沈砚停了一次大的。
不是换工具。他把两只手都从台上收回去，摘手套，走到水池边，凉水冲腕子，前后冲了很久。回来的时候路过门边，记录那位的笔还在走，纸上那一栏写着起止时刻，一行一行，密得像账。
他重新坐下，先把手背贴上没动过的铜面。
凉的。等两边一样凉了，再进签。
走廊里那排感应灯自己亮了一次。
没有人。灯照了一阵空走廊，又自己灭了。记录那位抬头看了一眼，低回去，笔接着走。
十二点整，他在本子上换了一页。新一页的页眉上，日期那一格写下去的是三月一日。
没有人说什么。第三天就这么变成了第四天，变在一支笔底下。
周维趁这个空当把台角归置了一遍。秃签一把，收进废料缸；新签补上，从宽到窄；表面皿换了空的，满的那只送到门边点收。做完他站回原位，手垂着。
他上一回这样站在一张台边，给台前的人递东西，是很多年以前的事了。
那时候台前那个人的工具，也是这么排的——从大到小，一支一支，排得笔直，最小的那支往前多出半寸。
他没有说。这间屋里凡是值得说的，都轮不到嘴。
马扎还在墙根，三天了，没人坐过。
夜里最深的那一阵，周维离它最近，一步。他把外套脱下来，叠成方的，搭在马扎上，人还是站着。
马扎有了用处。用处不是坐。
后半夜的缝越来越窄。
圈足那一段白天只清了个头，夜里溶剂泡透了，牛角刀那一线薄刃一点一点往里请。屑小得看不见，捻的颜色却一根比一根浅了——深处的胶在见底。
中间断了一支签。
不是失手。竹签在弯里吃了侧劲，自己折的，断口在缝外头，一声很轻的脆。沈砚把两截都退出来，前一截，后一截，并排收进皿里。器上下来的东西一样不少，断在活儿上的东西也一件不留——皿里的账，将来要跟记录那位本子上的对得上。
断签换新签。新签到手的时候，他的手还没抬到位。
一点过，最难的那一小段走完了。
沈砚往后靠了一下，脊背离开台沿，又回来。
还剩收尾。收尾不难，可收尾的手最容易松。他把头灯往上推了推，让眼睛歇了三口气的工夫，再落下来。
两点不到，缝里够得着的都请出来了。剩下那一星半点嵌在牙缝深处，签再细也无能为力——那是明天超声的活儿，今天夜里只剩收边。
最后一段，签要换成最细的那一支。
那支在案角最里头，隔着一排工具。按平常，他得自己直起腰去够，或者开口。
他伸手。
周维已经把那支放在他掌心里了。
两个人都没抬头。
