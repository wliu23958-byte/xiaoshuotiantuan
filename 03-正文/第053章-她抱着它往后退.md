# 第五十三章　她抱着它往后退

灯不对。
不是工作站那盏暖白的顶灯，也不是上一次那种从很远的地方压下来的绿白应急灯。
这一次的光是从下面往上走的。
它是黄的，是活的，一下一下地晃，把影子甩到墙上又收回来。空气里有烟，烟是从这团光里升上去的，升到一半散开，贴着梁往上走。
火。
堂中央燎着一堆火。
沈砚在这个念头刚成形的时候就没有了。
这一次不像上一次。
上一次他在一个比人矮的位置上，从器的位置往外看，看见一双戴手套的手。这一次不是。
这一次他有重量。
第一样报上来的是重量。
不是他自己的重量——是他怀里那一件东西的重量。
它压在胸口，压得肋骨往里陷。两条小臂从下面兜住器底，兜的角度不对，力全吃在腕子上，腕子已经在抖。手指扣在圈足的方座下沿，指节顶着一道棱。
第二样是热。
火在正前方，隔着七八步。脸上是烫的，眼睛干，睫毛在光里发涩。而背上是凉的——背后没有火。
第三样在左边。
方座有四个角，其中一个角正抵在左边的肋骨上。
不是磕一下就过去的那种抵。是持续的、越来越沉的、随着两条胳膊一点点往下坠而越陷越深的抵。它已经抵了很久，久到那一小块地方从疼变成了木，木下面又有一根更细的疼，一下一下地跳。
这具身体在痛，而它没有把这件东西放下。
沈砚知道自己在谁身上了。
他还知道另一件事，而这件事让他在里面停了一下。
他认得这个形状。
两条小臂兜住的是一个方的底座，四角有棱，棱是直的，往上收进去一道。再往上是圆的腹，腹壁往外鼓，鼓到最宽的地方正好卡在胸口下缘。左右各挑出一只耳，耳很厚，耳的下面还坠着一小片，垂在那里。
他这几天摸的就是这个形状。
不是像。
是同一个。
他量过它的口径，托过它的方座，跟何同志一人一边把它侧过九十度、再慢慢放平，用指腹一寸一寸推过它的圈足内壁。这个形状已经进了他的手，比进他的眼睛还深。
现在这个形状在另一个人怀里。
它是热的。
而且它是整的。
没有那道四十度的弧，没有那条比头发丝粗不了多少的缝，没有他今天下午压进去的那三段铜。
这一件从来没有被人拆开过。
沈砚想低头看一眼那两只耳。
他动不了。
眼睛不是他的，脖子不是他的，连什么时候眨一下都不是他能决定的。这具身体的眼睛在前面，就一直在前面。
然后声音进来。
第一声不是他听见的第一声。他知道这一点——他进来的时候，那个声音刚刚落下去，堂里还留着尾巴。
铜落在石头上的声音跟别的东西都不一样。
它不脆。它先是一记闷的，很短，像有人用掌根拍在一块厚木板上；紧接着才是裂——不是碎成很多块的那种碎，是一道裂从落点走出去，走到某处停住。
停住以后有余音。
那余音很长。它在堂里绕，绕过梁，绕过柱子，从四面回来，压过所有人的呼吸。
第二声起来的时候，第一声的余音还没有走干净。
两个声音叠在一起。
这具身体抖了一下。
不是怕。
沈砚很确定这一点，因为他就在里面。怕是有形状的——心跳先乱，手先松，眼睛先去找门在哪儿。这具身体一样都没有。它的心跳是重的、慢的、一下一下砸在耳朵里，两条胳膊不是在松，是在往里收。
它抖，是因为那一声太响了，响到骨头跟着响。
她往后退了一步。
不是跑，不是躲。
是退。
一步，很稳，脚跟先着地，脚掌再落下去，重心一寸一寸挪过去。抱着这么沉一件东西退步，只能这么退，快一点就要摔。
堂上还有别人。
沈砚看不清他们的脸。
不是烟挡着，也不是光不够。是这具身体不看脸——它的眼睛落在别处，落在一双一双的手上，落在那些手里托着的、举着的、正在往下砸的东西上。
她在看器。
从她进这间堂屋起，她看的就一直是器。
第三声。
这一次沈砚“看见”了——那件东西被举到齐眉的高度，往下一送。
送下去的姿势很怪。
不是砸。砸是要抡的，是要把整条胳膊甩出去的。那个人没有抡，他是把器举起来，然后放开手。
像放下一样东西，只不过下面是石头。
它落地，闷了一记，裂开。
沈砚在那一瞬间想起了一句话。
七缺一，盟自破。
第四声。
沈砚开始注意到一件事。
这些声音之间是有间隔的。
不是乱的。第一声和第二声之间隔着几息，第二声和第三声之间也隔着几息。没有人抢，没有两个人同时动手。一个人做完，退回去，下一个人才上前。
而且每一个人的动作都一样。
举到齐眉，停一下，放开手。
没有人抡，没有人喊，没有人把东西往别人身上砸。
这不是一屋子人在发疯。
这是一件正在被办的事。
有次序，有先后，一个接着一个。
沈砚这三年在库房里见过太多有次序的事——点交、核对、签字、入柜，一个人做完下一个人接上，中间谁也不越过谁。他认得这种节奏，他每天都在这种节奏里干活。
这一屋子人是在走一道程序。
而在这道程序里，她是其中的一个。
第五声。
然后堂上安静了下来。
安静得能听见火。
那些人没有走。
他们站在原处，脸朝着同一个方向。
沈砚看不见那些脸，可他知道那个方向在哪儿——因为这具身体的正面整个绷起来了，皮肤上那种被人看着的紧，从胸口一路提到下巴。
他们在看她。
他们在等她。
轮到她了。
有人在说话，说的是他听不懂的音。那些音在堂里挤成一团，混着余音和火的声音，一句也分不出来。
只有一句进来了。
不是别人的。
是这具身体自己的。
它从胸腔里出来，穿过喉咙的时候带着一层沙——她的嗓子哑了，已经说过很多话了，说到这个份上。
她说的是三个字。
沈砚不认得那些音。
可他知道那三个字是什么意思，因为那意思是从这具身体里一起涌上来的，跟声音同时到达：
我不砸。
说完她又退了一步。
有一只手伸过来。
从她的右前方，隔着两步，一只手朝她怀里的器伸过来——不是抢，手指是张开的，掌心朝上，那是一个“给我”的手势。
她把身子拧过去半寸，让那件东西离开那只手的方向。
就半寸。
因为她抱不动更多了。
那半寸让方座的角在左肋上又往里进了一分。
疼那一下是尖的。
她没有出声。
那只手在半空停了一会儿，收了回去。
第六声落下的时候，堂里的东西已经没剩几件了。
沈砚在这具身体里数了一遍——不是他要数，是这具身体在数。她一直在数。她从进来就在数。地上现在有多少，堂上还剩多少，谁的手里还是空的。
数到最后，剩下的是她这一件。
只剩下她这一件。
她又退了一步。
后退这个动作到这时候已经不是拒绝了，它变成了别的东西——她在把这件器往这间堂屋的外面挪，一寸一寸地挪，用她自己的身体挡在中间。
她不是在保命。
她要是想保命，把东西往地上一放就行了。放下去，她就跟他们一样了；放下去，那个角就不会再顶着她的肋骨；放下去，她两条已经不听使唤的胳膊就可以垂下来。
她没有放。
沈砚在里面，一动不能动，什么也做不了。
他只能感觉。
他感觉到这具身体的呼吸变浅了，感觉到腕子那一处的抖已经变成了整条小臂的抖，感觉到左边肋骨上那一点从木又变回了疼，感觉到指节扣在方座下沿的地方开始滑。
她把下巴压下去，抵在器的口沿上。
用下巴分掉一点重量。
这是一个很老的动作，抱不动东西的人都会这么做。
她又退了半步。
然后脚跟碰到了一个边。
是台。
堂屋后半是一方高起来的台，边沿是石的，磨得很平。她的脚跟撞在那道边上，停住了。
这具身体停了下来。
不是决定停的。
是退到头了。
沈砚从这具身体的皮肤上读到了一样东西：背后没有热，没有墙，没有任何挡着的东西。
后面是空的。
那口气她还没有喘匀。
她也没有回头。
她的眼睛还在前面那几个人身上，还在那些空掉的手上。
而在这具身体的耳朵里，在余音和火声底下，有另一样声音正从背后过来。
很轻。
一步。
又一步。
