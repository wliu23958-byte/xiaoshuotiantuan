# 第九十六章　笔停住了

十一月七日上午八点五十，江阳专案组临时驻地。
驻地是借的，原来是市局的一间业务用房，两扇窗朝北，靠墙一排铁皮柜，中间拼了四张桌子。墙上挂着白板，白板边上另钉了一张大纸——七行地名，从云梁往下数到南陵，字是陈延自己写的，跟省博那间大会议室墙上那七张一个笔迹。
白板上是六个名字。
那是上个月拉出来的那份，全国能干净撬开一层补配而不伤原胎的人，业内数得出来的不超过十个，四个已经死了，剩下这六个。六个名字后面各跟着一行小字：籍贯、现在的单位、近三年经手过的项目。有两行末尾画了勾，是已经跑完的。
陈延到得比谁都早。搬进这间屋子起他天天是这个点，进门先开窗，再烧水，水开之前把昨天的记录过一遍。
沈砚进来的时候他正在写。
姜宁在靠窗那张桌子上摆她的东西——笔记本电脑、一只移动硬盘、一沓打印出来的点云截面图，边角用长尾夹夹着。她抬头看了沈砚一眼。
他的外套没脱。
这不像他。他到哪儿第一件事都是把外套挂到门后那个钩子上，三年了没有变过。
沈砚在桌边站住。
陈延没有抬头，笔还在走：“坐。”
沈砚没有坐。
他昨天夜里没有睡。天亮之前他把箱盖重新装回去，工具一件一件按原位放回箱子，上面一层压下面一层，搭扣扣好，推回床底。做完这一套天已经灰了。
这一路上他想的是怎么开口。
这件事从他嘴里出去会是什么样子，他清楚得很。一个劳务派遣的修复工，拿着一块木头上的三个字，走进一间刑侦的屋子。木头不是物证，来源没有登记，年份不可考，錾字的人死了七年。这三个字换成任何一份材料他都递得出手，唯独换成这一块，他递不出来。
所以他没有想出办法。
他说了一个名字。
三个字，说得不快，一个字一个字落下去，像是怕说错。
笔停住了。
不是写完一笔停的。是走到一半停的——那一横还差最后一小段没有拉到头，笔尖压在纸上，墨在停住的地方洇开一小团，越洇越大。
他写的是昨天那一条的续页，左边一栏是时间，右边一栏是内容，这一行才起了个头。
屋里那台饮水机在这时候咕嘟了一声。
沈砚看着那支笔。
他和这个人是八月里认识的，在省博三楼那间灯全开着的会客室。从那时候到现在，他见过这个人在各种场合写字：在展厅里站着写，在协调会上一边听一边写，在深夜的驻地里写到笔没水了换一支接着写。这个人听见任何东西都是先写下来再说话，这是他的习惯，也是他的防线——先记，记完了才轮到判断。
这是第一次，笔比人先反应过来。
陈延抬起头。
“你再说一遍。”
沈砚又说了一遍。
陈延把笔从纸上拿开，那一小团墨已经洇成了指甲盖大的一块。他没有去管它，翻过一页，在新的一页上把那三个字写下来，写完推到桌子中间。
“是这三个字？”
“是。”
姜宁走过来了。她看了一眼那三个字，又看了一眼白板。
白板上没有。
六个名字里没有这三个字，这一眼谁都看得出来——那六行她抄过两遍，其中三个人的公开履历还是她跑的。
陈延也在看白板。他看了很久，久到墨在纸上不再往外走了。
然后他转身去开铁皮柜。
柜门有点卡，要抬着往外带。柜子里堆着这一案的卷宗，一摞一摞立着，脊上贴着标签，标签是他自己写的，字很小。上面两格是本案的，按地名分：清河、江阳。下面一格不是。
他蹲下去，从最底下靠里的位置抽出一摞。
那一摞用棉线捆着，线上有灰。它不是本案的材料，是从二〇一九年那一轮里接过来的旧底档，专案组成立的时候连同别的旧卷一并调了过来，签收单上有它，此后没有人动过。
他把它抱到桌上，解开绳子。
里面是打印件，页边发黄，纸比现在的薄。装订孔的位置对不齐，有几处是后来补打进去再夹上的。最厚的那一本封面上手写着四个字：外围排查。
陈延把那一本抽出来，平摊开。
后面是表格。横着印的，一页压着一页，每一行一个人，列头依次是：姓名、来源、核查方式、结论、经办。行距很密，一页能装下二三十行，每一行都填满了，没有一格空着。填的人字迹不止一种，有的用蓝笔，有的用黑笔，有几页是同一种字从头写到尾，写到后面越写越连。
陈延从最后往前翻。
他翻得不快。翻的时候他不是在找，是在看——看这一本有多厚，看这些行是怎么被填出来的。纸一页一页翻过去，能听见它的重量。姜宁站在他旁边，沈砚站在桌子另一头，谁都没有说话。
饮水机又响了一声。
翻到一半他停了。
他把那一页转过来，摆平，用食指压住其中一行。
那一行的姓名栏里，是那三个字。
结论栏两个字：已排除。
再往后一格是理由。
理由栏三个字。
已故。
陈延没有说话。他把那一页从头到尾看了一遍，又回到那一行上，用指节在纸上顿了一下。
沈砚看着那一行。
一块榆木上錾着这三个字，划着一道横杠。一份七年前的表格上印着这三个字，写着已故。
一个是他爷爷在南陵老修复间里用錾子一下一下敲出来的，木头是自己家的，锤是自己的，那一夜屋里大概只有他一个人。另一个是某个他不认识的人，在某间办公室里，照着某一份材料，填进一张横排表格的第四格。
这两样东西之间没有任何关系。它们不在同一个地方，不出自同一双手，不属于同一套系统，甚至不是为同一件事做的——一个是师徒之间的账，一个是案子的外围排查。做这两件事的人这辈子多半没有见过面。
而它们说的是同一句话。
一件事被两个互不相干的来源说中，在他这一行里是最硬的一种证据。两份材料各来各路，谁也没抄谁，最后落在同一个结论上——这种时候通常就不必再查了。
昨天夜里他刚给自己立了一条规矩：一个点得不出一件器。
现在他有两个点。
两个点落在同一处，说的是同一件事：这个人不在了。
姜宁把那一页往自己那边转了半圈，看列头，看那一行，又看了看这一页的页码。
她做检测的人，看一份数据先看的不是数，是这份数据是怎么得来的。
“这一栏，”她的手指停在核查方式那一格上，“这里填的是什么。”
陈延看了一眼。
“走访。”
“三个字就一栏？”
“这一本里大部分都是三个字。”
姜宁没有再问，把那一页转了回去。
她先出的声。
“两边都说这个人不在了。”
陈延还在看那一行。
“嗯。”
“那这个名字为什么不在白板上。”
“因为它在这儿。”陈延用指节又敲了一下那一页，“排除过的人不会再进新名单。这本底档就是干这个用的，替后面每一轮省掉已经问过的人。”
他把那一页折了个角。
然后他抬起头，看着沈砚。
沈砚身上还穿着外套，两只手垂在身侧，指甲缝里那点铜绿在窗户的光里看得很清楚。
陈延问了一句。
“你从哪儿看来的。”
“我爷爷的工具箱上。”
