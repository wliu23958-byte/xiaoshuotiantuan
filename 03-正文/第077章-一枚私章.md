# 第七十七章　一枚私章

十月二十一日上午九点半，库房档案室。
核查有一条规定动作沈砚昨天没走完：一件东西的账对不上，要看同一批进来的其他东西有没有一样的毛病。
批是有意义的。同一天、同一个渠道进来的一批，往往是同一个人经手、同一杆秤称的、同一支笔记的。要是这一批里有好几件都对不上，那就是当年那一次入库出了系统性的问题，跟东西本身没关系。
“这个好查。”老猫说，“总账是按进来的先后排流水号的。同一天进来的，在账上就是挨着的几行。”
他把昨天那本册子重新搬出来，翻到那一页。
“你看。”
那一行的上面和下面都还有字。往上数几行，往下数几行，入藏日期那一栏是同一个日子。来源那一栏也大半是同样的四个字。
“这一批一共这些。”老猫用手指从上到下划了一道，“不多。”
沈砚跟着那一道往下看。
铜钱，一封。铁器残件，一件。木质印章，一枚。银锭，一枚。瓷碗，两只，一只残。木尺，一把。
七行。
规定动作是把这七行一件一件核过去。
铜钱那一封，账上记的是枚数，不记重量，核不了。铁器残件，同样。瓷碗两只，记的是尺寸，量了，对上。木尺一把，记的是长度，量了，对上。
剩下能称的只有银锭。
“金银器才复秤。”老猫说，“别的类别没有这一条。”
所以这一批里，能验出账实差的位置只有一个，而那一个正好就差了。
这说明不了什么。它既不能证明当年那一次入库出了系统性的问题，也不能证明没出——七件里只有一件被验过，剩下六件是没验过，不是验过没事。
沈砚在核查表上把这一条照实写了：本批其余六件不具备复秤条件，未能比对。
写完他把笔搁下。
这一行字将来会被人读成“没问题”。它写的其实是“不知道”。
“分类号呢。”
“分类号在这儿。”老猫翻到另一本，“这一本是分类账。”
分类账和总账是两套东西。总账管的是进来的顺序，一件一个流水号，进来一件记一件，永远往后加。分类账管的是东西本身的类别——金银器一类，陶瓷一类，竹木牙角一类，杂项一类。同一批进来的东西，在总账上是挨着的，到了分类账上就各走各的门。
老猫把两本并排摊开。
同一天进来的那七件，在总账上是连着的七行；在分类账里，它们分在四个不同的类别底下，编号的头几位互不相同。
“东西入库以后就归类了。”老猫说，“归了类，往后一辈子按类别管。取的时候按类别取，点的时候按类别点，做展览按类别挑。”
“批号呢。”
“批号在总账上留着。”老猫说，“可平时没人看总账。总账是流水，厚，谁没事翻它。”
沈砚看着分类账上那几行。
金银器那一格里，那枚银锭的号旁边是别的银器；竹木牙角那一格里，那枚木质印章的号旁边是别的木器。两个号中间隔着不知道多少个格子，隔着不知道多少个架子，也隔着不知道多少年。
“那枚印章能取出来看吗。”
“能。核查范围之内。”
木器那几架在库房最里头，温湿度控制得比别处严一档。木头怕的和银不一样，银怕硫，木头怕干——干了缩，缩了裂，裂了就再也回不去。
匣子很小，一只手就能拿。
打开是一枚印章。
不大，比拇指粗一点，长不过一节手指。木是深褐色的，看不出是什么木，年头久了以后什么木都往一个颜色上走。章身是素的，没有雕，没有边款，四个面都被摸得发亮，尤其是中间那一段——那是拇指和食指常年捏着的地方，捏出了一个很浅的窝。
章身上有一道裂。
裂是顺着木纹走的，从中段一直到底，很细，不裂穿。木头在库里放久了会失水，失水就往里缩，缩不均匀就顺着纹路裂开。这道裂的两边没有错位，也没有翘，是慢慢裂的那种。
底面靠近印面的一圈还留着一点红。
那是印泥。年头太久，油走光了，只剩下颜料压在木头的孔里，颜色发暗，不像朱红，像干掉的血。用棉签蘸乙醇碰一下不会掉——它已经不是浮在表面的东西了，它渗进去了。
顶上没有钮。
有些私章会在顶上做一个小钮，方便捏，也好看。这一枚没有，顶就是一个平面，平面上有一道浅浅的刻痕，横的，是给人认方向用的——摸到这道痕就知道印面该朝哪边。
这道痕不是刻章的人留的，是用章的人自己拿刀尖划的。划得歪，深浅也不匀。
沈砚把它翻过来。
印面朝上。
第一眼看过去是一片平的。
木质印章用久了会磨。纸有毛，纸下面垫的东西有硬有软，一次一次盖下去，凸起来的笔画就一点一点被磨矮。磨到最后，阳文变成平的，只在笔画之间还留着一点点凹。
这一枚就磨到了那一步。
老猫凑过来看了一眼。
“这看不出来了。”
沈砚没有说话。他把那盏臂灯拉过来，压得很低，几乎和台面平齐，让光从侧面横着扫过去。
平面上出现了影子。
极浅的影子，一道一道，深的地方黑一点，浅的地方几乎没有。它们连起来是一个方框，方框里有笔画。
沈砚把印章慢慢转了一圈。
转到某一个角度的时候，笔画忽然清楚了一点。
一个字。
不是两个字，也不是四个字。这枚章上只刻了一个字。
一个姓。
哪一个姓，看不出来。剩下的那点凹里，横是横，竖是竖，可它们已经不完整了——有的笔画断在中间，有的只剩一头。凑得出一个大致的轮廓，凑不出一个字。
沈砚看了很久。
他把灯换到另一侧再看了一遍，让影子倒过来。影子倒过来以后有两笔看得清楚一点，另外几笔又糊掉了。
两次看的结果拼不成同一个字。
他停下了。
再往下就是猜。猜出来的字会被人当成认出来的字，写进哪一张表，再被下一个人当成依据。这一行里最要不得的就是这个。
“是个姓。”他说。
“哪个姓。”
“不知道。”
老猫嗯了一声，也没有再追。
他去把银锭那只匣子也取了过来。
两只匣子摆在长台上，一大一小。老猫打开小的那只，沈砚打开大的那只。
木质印章拿出来，放在台面正中。
银锭拿出来，放在它旁边。
它们挨得很近，中间隔着大概一个指节。
台面上什么都没有了，只有这两样东西。
一枚被人捏了很多年、捏出一个浅窝、印面磨得只剩影子的木章。
一枚被人一角一角凿开、只剩下一个壳的银锭。
它们是同一天进这栋楼的。
进来那一天，它们是一起被人放在桌上的——总账上那七行字挨着，写字的人一支笔从上往下写了下来，中间没有停。
写完那七行，它们就被分开了。
一个归金银器，一个归竹木牙角。分开的理由写在制度里，四个字：并无关联。
这四个字没有错。一枚银锭和一枚木章，材质不同，用途不同，年代也未必一样，把它们放进同一个类别才是乱来。分类是为了找得到东西，不是为了讲故事。
它们于是各躺各的号。
一个躺在这一头，一个躺在那一头。中间隔着七十年。
七十年里，这栋楼清点过很多次，搬过库，换过人，账从毛笔换成钢笔又换成打印。每一次清点它们都在，每一次都被人从匣子里请出来看一眼，画一个勾，再放回去。
七十年里没有一个人，把它们放在同一张桌子上。
